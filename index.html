Help

      


        

          Builds input JSON files for AF3x,
          the AlphaFold 3 fork from the
          Kosinski Lab (EMBL)
          that models each crosslink as a linker molecule bonded to both residues. Files without crosslinks
          also run in plain AlphaFold 3.
        


        
Quick start

        
    
          
  1. Paste a sequence, FASTA or UniProt ID into a chain, or drop a FASTA / PDB / mmCIF file on the page.
    2. 
          
  2. Click two residues to crosslink them, type the pairs, or import an xiVIEW / xiNET CSV.
    3. 
          
  3. Name the job and download the JSON. Run it with run_alphafold.py --json_path=job.json.
    4. 
        

        

          Disulfides, bonded atoms and custom ligands are under + More; modifications, MSA and templates
          in each chain's ⋯ menu or the bar that opens when you click a residue. Advanced options
          (press /) searches all of them, plus batch export.
        


        
Crosslinkers

        

          Asymmetric linkers have two different ends: the NHS-ester end goes first. The tool puts the pair in
          that order in the JSON when only one order is possible. LINKn and
          RIGIDn are generic linkers of n carbons or fused rings.
        

        


        
Crosslink CSV

        

          xiVIEW (Protein1, AbsPos1, Protein2, AbsPos2) and xiNET
          (Protein1, PepPos1, LinkPos1, Protein2, PepPos2, LinkPos2) are read directly. Convert
          other formats first, for example with
          pyXLMS.
        


        
Good to know

        
    
          
  • Residue numbers are 1-based positions in the sequence you entered, not PDB numbering.
    • 
          
  • To edit a sequence, click beside its letters or double-click it. Once a chain has crosslinks,
            modifications or other settings, use the pencil button, so they are not shifted by accident.
    • 
          
  • AF3x drops a crosslink whose residue is already used by an earlier one, unless it runs with
            --noremove_overlapping_crosslinks.
    • 
          
  • Each seed gives 5 models. More seeds sample more; run time grows with them.
    • 
          
  • A disulfide is modelled as Cys→Ala plus an S–S linker.
    • 
          
  • A chain with custom templates also needs its MSA set to None or Custom (an AlphaFold 3 rule).
    • 
          
  • Template residue mapping is 0-based. Uploading a structure aligns it to the chain and fills the
            mapping; check it before use. PDB files are converted to mmCIF.
    • 
          
  • MSA, template and ligand files can be uploaded (stored inside the JSON) or given as a path on
            the machine that runs AF3x.
    • 
          
  • The chain name is saved as description and does not affect the prediction.
    •

Privacy

        

          The generator runs entirely in your browser; your sequences and inputs are not uploaded anywhere.
          Your current input is autosaved in your browser's local storage; New clears it.
          Fetching by UniProt ID sends that ID to UniProt. The ZIP export loads the JSZip library from
          jsDelivr, which sees your IP address. The site is hosted on GitHub Pages, which logs visitors'
          IP addresses
          (GitHub privacy statement).
